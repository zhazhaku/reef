# 单用户场景方向设计：reef + ESP32-S3 ePaper

> **设计日期**：2026-06-22
> **硬件**：ESP32-S3 + 1.54" 200×200 电子纸 + 麦克风/扬声器 + 1 按键 + LED + BLE/WiFi + 锂电
> **设计原则**：≤1 个动作触发、发挥 ePaper 零功耗常显、每个方向回答"为什么不用手机"

---

## 方向 1：「情绪像素」

**场景故事**
小鹿把情绪像素放在工位显示器旁。今天周一早会开了 2 小时，她回到工位按了一下说「今天像被踩了一脚的泡面」，3 秒后屏幕浮现一幅像素画：一个小人蹲在泡面旁 😫——这张画在墨水屏上待了一整天。同事路过瞥一眼，把到嘴边的需求吞了回去。

**核心交互（≤1 动作）**
- 平日：屏幕常显上一次的情绪像素画 + 关键词 + 时间戳
- 动作：**按一下按键 + 说一句话**（"今天赢了 Dota""被老板骂了""困成狗"）
- 反馈：ASR→reef LLM 情绪分析→局刷更新像素画 + LED 呼吸灯切情绪色（暖橙=积极/冷蓝=低落）+ 扬声器轻声反馈（"赢了好！"或"摸摸 🥺"）
- 收尾：像素画常显直到下次更新，24h 无操作自动切 😶 待机

**为什么不是手机/手表/Kindle**
- 手机：锁屏能放 emoji，但 5 分钟后被微信通知盖掉。且你不会盯着手机锁屏看——它是工具。情绪像素是桌面上那件"活的艺术品"。
- Kindle：太大（半张桌子）、没有麦克风/语音输入、没有 LED 氛围灯。且 Kindle 的阅读属性与"桌搭潮玩"气质相悖。
- **ePaper 独特价值**：墨水质感天然适配像素艺术（像版画不像屏幕），零功耗常显 = 情绪成为物理存在而非数字气泡。

**硬件可行性**
- 日刷新：5-10 次 | 续航：7-14 天 | 全用到：屏+麦+喇叭+按键+LED+WiFi+电池
- 风险：LLM 口语情绪分析准确度——"被踩了一脚的泡面"需要模型理解隐喻

## 方向 2：「晨间卡片」

**场景故事**
大雄把晨间卡片放在床头柜。每天 6:45，屏幕悄无声息地局刷更新——没有刺耳的闹铃、没有蓝光刺激、没有"您有 3 条新消息"。他自然醒来时，一张卡片已经等在那儿：「🌅 今日小雨 8°C | 📅 10 点周会 | 💬 你唯一要做的就是开始——邱吉尔」。如果想听，按一下就有温柔的女声 TTS 播报。

**核心交互（≤1 动作）**
- 平日：夜间显示"🌙 晚安 | 明早 6:45 见"；白天常显今日卡片
- 动作：**零动作**（卡片自动生成）。可选按一下按键 → TTS 播报 + 切换查看日历详情
- 反馈：定时 6:45→LED 5 分钟渐亮暖黄光（模拟日出）→ 局刷显示卡片→可选 TTS
- 收尾：全天保持卡片常显，每小时局刷更新天气，22:00 自动切晚安画面

**为什么不是手机/手表/Kindle**
- 手机：闹钟 = 蓝光 + 通知轰炸 + 你醒来先刷 10 分钟短视频。且手机锁屏的天气是冰冷的数据行，晨间卡片是 reef LLM 用你的语气生成的"一张便签"。
- 智能音箱：能播报天气，但没有持久显示。你听完就忘了温度数字。ePaper 卡片一直在那，你刷牙回来还能看一眼。
- **ePaper 独特价值**：慢刷新 2-3 秒恰好模拟"翻一张卡片"的物理仪式——像酒店门缝塞进来的报纸，不是数字屏的跳变。

**硬件可行性**
- 日刷新：10-20 次 | 续航：7-14 天 | 全用到：屏+喇叭+按键+LED+WiFi+电池
- 风险：每日一句 LLM 质量——需要精调 prompt 避免"鸡汤味"太重

## 方向 3：「感恩石」

**场景故事**
阿杰是一个焦虑的产品经理，每天睡前脑子里全是明天要开的 3 个会。他的心理咨询师建议每天睡前写"今天一件感恩的事"——但他总是忘，直到把感恩石放在枕头边。每晚躺下，按一下说"今天感恩：楼下咖啡师多给了我一份浓缩"。屏幕显示"☕ 23:03 | 咖啡师的善意"。30 天后，他长按按键翻看——屏幕上像翻书一样逐张闪过过去 30 天的感恩卡片。"我居然有这么多好事"。

**核心交互（≤1 动作）**
- 平日：屏幕常显最新一条感恩卡片（日期 + 内容摘要）
- 动作：**按一下按键 + 说一句**"今天感恩 xxx"
- 反馈：ASR→reef LLM 提炼为简短卡片→局刷显示+LED 暖黄微亮 3 秒+扬声器轻声"已记录 ✨"
- 收尾：卡片常显直到下次记录。长按进入翻看模式（逐页局刷历史卡片）。每晚 22:30 若未记录 LED 轻柔呼吸提醒（可关）

**为什么不是手机/手表/Kindle**
- 手机：打开备忘录→被微信通知打断→刷 15 分钟朋友圈→忘了要写什么。感恩石没有浏览器、没有推送——它是一个"只会感恩的石头"，这种**单功能限制本身就是产品价值**。
- 手表：屏幕太小打不了字，语音输入后内容消失在手表深处再也不会被翻看。
- **ePaper 独特价值**：翻页的物理仪式——30 张卡片逐张局刷闪过的视觉积累，远胜手机上滑一个列表。这种时间累积的物理感没有任何像素屏能做到。

**硬件可行性**
- 日刷新：2-5 次 | 续航：30-60 天 | 全用到：屏+麦+喇叭+按键+LED+WiFi+电池
- 风险：使用频次极低（日 1 次），需极强的仪式感设计防止吃灰

## 方向 4：「数字盆栽」

**场景故事**
小雨在工位上养了一盆"数字盆栽"——屏幕上是一棵像素小树苗 🌱。每天到工位，她按一下按键 = 浇水（屏幕上水滴落向树苗）。长按说"今天阳光真好"= 施肥（reef LLM 从话里提取"积极情绪量"兑换成长值）。树苗每天长 1-3 个像素，3 个月后长成一棵像素大树。如果她连续 3 天没互动，树开始掉像素叶子 🍂——提醒"你没照顾好自己"。换季时，reef LLM 根据季节自动换树的外观（春天的樱花、秋天的红叶）。

**核心交互（≤1 动作）**
- 平日：屏幕常显当前像素植物 + 年龄天数 + 健康状态（绿叶=好/黄叶=警告）
- 动作：**按一下 = 浇水**（最简操作）；可选 **长按+说话 = 施肥**（加分项但不必须）
- 反馈：浇水→局刷播放 3 帧水滴滴落动画→LED 蓝灯闪烁→扬声器"咕噜"水声
- 收尾：植物常显。午夜全刷更新当日总成长（新增像素数）。24h 未互动 LED 呼吸提醒

**为什么不是手机/手表/Kindle**
- 手机：Tamagotchi/旅行青蛙都在手机里，但你会切出去回微信——"你的宠物"和"你的老板"抢同一块屏幕，情感链接被持续打断。数字盆栽独占一块物理屏幕——**它不被任何推送打扰**。
- Kindle：没有语音互动、没有 LED、没有动画帧能力。且带着 Kindle 到处走不现实。
- **ePaper 独特价值**：慢生长 x 慢刷新 = 天生契合。像素树每天才长 1-3 像素，电子纸局刷 0.5 秒更新一帧足够。**LCD 屏的"快"反而会毁掉"慢生长"的禅意**。

**硬件可行性**
- 日刷新：3-6 次 | 续航：14-30 天 | 全用到：屏+麦+喇叭+按键+LED+WiFi+电池
- 风险：长期留存——3 个月养成周期内需持续提供新鲜感（换季/特殊事件/果实收获）

## 方向 5：「口袋诗文」

**场景故事**
阿姚每天挤 45 分钟地铁通勤，手机电量出门时只有 60%。她把口袋诗文揣在大衣兜里。上地铁后掏出来按一下——屏幕局刷显示 reef LLM 根据她的阅读偏好生成的一篇短文：今天可能是博尔赫斯的半页诗，可能是《山海经》的白话解读，也可能是一段冷知识"为什么微波炉里的葡萄会喷火"。读完按一下翻下一页，全程不掏手机、不耗手机电、不被推送打断。到公司时，手机还有 52% 的电。

**核心交互（≤1 动作）**
- 平日：屏幕显示今日推送标题 + 第一段（昨晚 WiFi 定时拉取）
- 动作：**按一下按键** = 翻到下一页
- 反馈：局刷 0.3s 更新下一页。连续按 3 下 = 回首页。长按 = TTS 朗读当前页
- 收尾：读完末页回首页。每篇读完 reef 记录已读，影响次日推送

**为什么不是手机/手表/Kindle**
- 手机：你打开手机去"读诗"时，90% 会先刷微信/微博/Twitter。这个设备没有那些东西——它是一个**只读设备**。
- Kindle：需要提前选书下载。口袋诗文每天自动"变"出新内容，不需要你做选择——**克服内容选择瘫痪**。Kindle 是"你去找书"，诗文是"书来找你"。
- **ePaper 独特价值**：1.54 寸 200×200 每屏恰好 40-60 个汉字，读一首短诗刚好。在地铁上单手握住，Kindle 太大、手机太分心。电子纸的慢翻页不是 bug 是 feature——让你慢下来读。

**硬件可行性**
- 日刷新：10-30 次（翻页阅读）| 续航：7-14 天 | 全用到：屏+喇叭+按键+LED+WiFi+电池
- 风险：内容质量是核心——LLM 生成短文若"AI 味"太重用户会弃用。需精调 prompt + 多源内容丰富生态

## 方向 6：「专注符咒」

**场景故事**
阿伟是个程序员，和设计师女友在同一个客厅工作。最大的矛盾是："我在写代码时她开始刷抖音"。他把专注符咒放在显示器下方，按一下说"写代码 90 分钟"→ 屏幕局刷显示"⚡ 深度专注 | 90m | 请勿打扰"→ LED 发暖橙色。女友路过瞥一眼，自动戴上耳机。90 分钟后，屏幕显示"✅ 完成" + reef LLM 鼓励"第三段了，今天的 bug 没你多 🏆"。如果中途女朋友想紧急打断，只能在**自己的设备**上按三下发送一个"戳一戳"，符咒屏幕短暂显示"❤️ 小鹿找你"。

**核心交互（≤1 动作）**
- 平日：屏幕显示"🟢 空闲"或上次专注统计"上次 52min | 今日 3h12m"
- 动作：**按一下按键 + 说任务和时长**（"写周报 25 分钟"）
- 反馈：ASR 解析→局刷倒计时+LED 暖橙→每 5 分钟局刷更新进度条→结束 TTS 叮一声+LLM 鼓励
- 收尾：休息 5 分钟后回空闲。短按 = 提前结束。长按 = 查看今日/本周统计

**为什么不是手机/手表/Kindle**
- 手机：番茄钟 APP 最大悖论——需要打开手机设置，但手机就是分心源头。且你手机上的勿扰模式只有自己知道——别人还是会来打断你。专注符咒是一个**全屋可见的"勿扰牌"**。
- 智能音箱：能播报倒计时，但没有视觉常显。别人不知道你设了多久、还剩多久、能不能等。
- **ePaper 独特价值**：常亮倒计时 = 物理结界信号。LCD 屏也可以但会发热、费电、需要接电源线。电子纸零功耗常亮 + 锂电随身 = 放哪都行。

**硬件可行性**
- 日刷新：30-40 次（每 5 分钟局刷）| 续航：2-4 天 | 全用到：屏+麦+喇叭+按键+LED+WiFi+电池
- 风险：刷新频次较高导致续航偏短，建议 V2 引入深度睡眠间歇唤醒（如只在头尾 5 分钟活跃刷新）

## 最推荐：方向 ①「情绪像素」🥇

### 三维度理由

**硬件契合度 ★★★★★** — 7 项硬件能力全部用上且每项有不可替代的角色：电子纸的墨水质感 + 200×200 正方形天然是像素艺术画布；麦克风+扬声器形成语音情绪闭环；LED 氛围灯映射情绪色；按键是唯一的触发器；锂电随处放=真正的桌搭自由。没有任何一个硬件是凑数的。日均 5-10 次刷新在电子纸生命周期中几乎不可见。

**市场新颖度 ★★★★★** — 它同时踩中三个爆款赛道：(a) Z 世代桌搭/谷子经济——泡泡玛特用户天然会被"桌上一块会变表情的小砖头"吸引；(b) AI 生成式艺术——Midjourney 用户渴望看到 AI 生成的内容有物理载体；(c) 反手机情绪表达——年轻人厌倦了在社交 APP 里选 emoji 状态（太刻意），"说一句话→变成一张画"的生成式链路更真实更脆弱。市面无竞品——Fuzozo 芙崽和 Moflin 是毛绒玩具赛道，情绪像素是"桌搭潮玩 + AI 生成 + 电子纸"的品类创新。

**落地难度 ★★☆☆☆** — MVP 仅 6-8 人天。核心链路（ASR→LLM 情绪分析→像素匹配→ePaper 渲染）每环节都有现成方案：ASR 用 xiaozhi-ai 的 esp-sr、LLM 情绪分析一条 prompt 即可、像素表情库可预设 48-64 个模版（覆盖喜怒哀乐+日常吐槽）。最难的部分"隐喻理解"（"被踩了一脚的泡面"="破防"）可通过关键词回退 + 置信度阈值策略规避——低置信度统一匹配默认疑惑表情并反馈"没太懂，但帮你画了一张"——这种"笨拙的诚意"反而是产品魅力。

**为什么是情绪像素而不是晨间卡片**：晨间卡片落地难度更低（几乎无技术风险），但差异化壁垒也低——容易被"手机锁屏天气 widget + ChatGPT 一句话"复制。情绪像素的三个赛道交汇（桌搭 + AI 生成 + 情绪表达）构建了更高的品类壁垒，且有天然社交传播性（同事问"这什么"= 每台设备都是广告位）。
